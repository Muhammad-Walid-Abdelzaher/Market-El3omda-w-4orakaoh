# Market El3omda w 4orakaoh | ماركت العمدة وشركاؤه

A smart supermarket software that uses AI to make running and shopping
at a supermarket faster, easier, and more efficient.

## What does it do?
- Inventory management, with stock tracking and low-stock alerts
- Sales and checkout (POS) handling
- AI-powered features, such as tracking supplies
- Reports and analytics for owners and managers

## Tech stack
Language used: Python
Database: SQL Server
